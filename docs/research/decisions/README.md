# Research decisions

Decisions about the research and its documentation: methods, datasets, metrics, settings, the protocol, and how the research docs themselves are organized.

Technical and organizational decisions (the repository, the environment, the cluster) are [engineering decisions](../../engineering/decisions/README.md) (`ED-`).

**Decisions are rationale, not the documentation.** How things work is described in the research docs ([literature](../literature/README.md), [knowledge](../knowledge/README.md), [method](../method/README.md), this area's READMEs), which link here for the *why*.

## Rules

The same rules and template as the [engineering decisions](../../engineering/decisions/README.md#rules), with these differences:

- **Ids:** `RD-NNNN`, in files `RD-NNNN-short-slug.md`; the next id is the **highest id used** (below the index) plus one. Ids never change and are never reused.
- **Questions they answer** are research questions (`RQ-NNNN`, [questions/](../questions/README.md)).
