# Research questions

Open questions about the research: what this thesis asks and hasn't answered yet, and what is still undecided about its methods, data and evaluation.

Technical and organizational questions are [engineering questions](../../engineering/questions/README.md) (`EQ-`).

## Rules

The same rules and template as the [engineering questions](../../engineering/questions/README.md#rules), with these differences:

- **Ids:** `RQ-NNNN`, in files `RQ-NNNN-short-slug.md`; the next id is the **highest id used** (below the index) plus one, never reused.
- **Closing a question:** its answer goes into a research decision (`RD-NNNN`, [decisions/](../decisions/README.md)), a method doc, or a finding.
- **A research question may stay open for the whole thesis,** when it's what the experiments answer: each [experiment doc](../method/README.md) links the questions it addresses.
